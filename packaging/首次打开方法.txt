首次打开方法（未公证预览版）

本包尚未经过 Apple 公证，macOS 可能提示「无法验证开发者」
或「Apple 无法检查其是否包含恶意软件」。这类提示不等于文件损坏，
但也不代表文件已经通过 Apple 的安全检查。

仅在确认文件来自本项目的 GitHub Release 时继续：
https://github.com/qingye-lab/session-share/releases

1. 把「会话合并.app」拖入「应用程序」文件夹。
   如果是 DMG，复制完成后再推出磁盘映像；不要直接在映像里运行。

2. 在「应用程序」中尝试打开一次。
   若弹出安全提示，点「完成」「好」或取消；不要点「移到废纸篓」。
   按钮文字因 macOS 版本不同而有所区别。

3. 打开「系统设置」→「隐私与安全性」，滚动到「安全性」区域。
   在「会话合并」被阻止的提示旁，点「仍要打开」（Open Anyway）。
   此选项通常只在尝试打开后的约一小时内出现；没有看到时重新尝试一次。

4. 根据提示使用 Touch ID 或 Mac 登录密码授权，再点「打开」。
   这会为这个 App 添加例外，不需要把系统改为允许任意来源应用。

5. 打开后，请看屏幕顶部菜单栏的一叠卡片图标。
   这是菜单栏程序，不会出现普通主窗口或程序坞图标。
   后续通常可以正常双击打开，无需重复添加例外。

如果仍打不开：

• 如果提示「已损坏」「将损坏你的电脑」「包含恶意软件」或证书被撤销，
  不要按上面的流程强行放行。重新从官方 Release 下载并核对 SHA256SUMS.txt；
  若仍有同样提示，请在 GitHub Issues 反馈提示原文与 macOS 版本。
• 公司或学校管理的 Mac 可能不允许添加例外，需要联系设备管理员。
• 本版本只支持 M 系列（Apple Silicon）Mac、macOS 14 或更新版本。
• 无需运行终端命令，无需关闭 Gatekeeper，也无需关闭 SIP。
